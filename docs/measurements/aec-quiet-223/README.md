# Quiet AEC timing, PR #223

Controlled four-share comparison of shipped Left warm P7 against main, run on
2026-11-04 (UTC 20:31–21:28) on the owner's Mac.

- Head: `7699190642dc4ff737f7218a22ce1a319902c7fc` (PR head with main merged).
- Main: `6c1c45c9d677b63f6b61ba25a91fcd997a014ca1` (the merge base).
- Separate release test binaries (`build-aec-pair.py`, actual nice 10, four
  Cargo jobs, separate targets), recorded in `binaries.json`.
- Every run is the unchanged six-pair
  `voice::codec_tests::four_shares_leave_the_voice_pipeline_on_time`
  (`--exact --ignored --nocapture --test-threads=1`). Its source and its three
  pipeline helpers are identical on both revisions; head only adds a separate
  ignored option test next to it.
- Order head/main/head/main/head/main, three valid runs each
  (`run-aec-quiet-timing.py --start-load 3.5 --max-load 4.5`). An attempt starts
  only at one-minute load <3.5 and is voided if load exceeds 4.5 at any sample,
  another cargo/rustc/test or #213 share-sync timing overlaps, or the clock shows
  sleep or lost coverage. `pmset -g log` shows no sleep or wake in the window.

All 18 attempts are kept: six valid, eleven voided for an overlapping `cargo` /
`rustc` from another worker, and one voided at load 4.93. Each attempt has its
raw output (`NN-arm.txt`) and conditions (`NN-arm.meta.json`); `attempts.csv`
lists them. Per-second load samples and the preflight log were kept locally and
are summarised by each attempt's start/peak/end load. `report.md`, `runs.csv`,
`pairs.csv` and `comparisons.csv` are regenerated by
`python3 docs/measurements/summarize-aec-quiet.py docs/measurements/aec-quiet-223`.

## Result: PASS

| | Head (P7) | Main |
| --- | --- | --- |
| Valid runs / pairs | 3 / 18 | 3 / 18 |
| Max p99 delta, ms | **+0.966** | +0.655 |
| Median / mean p99 delta, ms | +0.502 / +0.301 | +0.170 / +0.195 |
| Mean four-share p99, ms | 0.834 | 0.842 |
| Mean no-share p99, ms | 0.533 | 0.646 |

Head max is <=1.0 ms. Head is not systematically worse than main: the absolute
four-share p99 is the same on both (0.834 versus 0.842 ms; permutation p=0.96),
and the higher head median delta comes from lower no-share baselines in the
same runs (0.533 versus 0.646 ms). The delta difference is not significant
(permutation p=0.40, Mann–Whitney U/n² 0.61). By adjacent block, head minus main
median delta is -0.151, +0.379 and +0.321 ms; max delta -0.013, +0.463 and
+0.097 ms. All 36 pairs are in `report.md`.

The test uses virtual headphones, AGC on, denoising 0 and no leading audio in the
release dev-feature test binary. It does not measure denoise-100 worker
scheduling or hardware latency. No audio device is opened.
